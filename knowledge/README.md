# Playbooks (kept on your computer only)

Every agent reads every `.md` file in this folder as its rulebook. Put a copy of these
skills here, keeping their folders:

    knowledge/danny-brain/SKILL.md
    knowledge/danny-brain/references/*.md
    knowledge/danny-brain-supreme/SKILL.md
    knowledge/hemant-audit/SKILL.md

Download them from claude.ai: Settings -> Capabilities -> Skills -> (skill) -> Download.

This folder is excluded from git, so the playbooks are never uploaded to GitHub.
